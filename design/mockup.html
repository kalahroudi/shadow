Design rationale

Plain HTML for fast review; every control maps to a SwiftUI/AppKit primitive (see “Native mapping”).

Visual language

Quiet instrument panel. The overlay is frosted glass (NSVisualEffectView / glass effect on macOS 26) so the meeting stays visible behind it; windows are flat system surfaces. One accent (violet→blue, tied to the icon) is reserved for state: active persona, streaming caret, selection. Green/amber/red only for provider health and recording.

Typography

SF Pro (system font), 13 pt body as in macOS controls, 11 pt uppercase tracked section labels, 20 pt pane titles. SF Mono only for code, keys and timestamps. Speaker labels (THEM / YOU) use colour and text, never colour alone.

Why it feels native

Real NSPopover with arrow from a template status icon; traffic-light windows with toolbar and sidebar; tinted sidebar selection; keycaps for shortcuts; segmented controls, switches and pop-up buttons with system metrics; whole-row hit targets; “Settings save automatically”; light/dark from the system with an explicit override that also themes the popover.

Overlay principles

1) Glanceable: ≤ 4 bullets, answer starts with the result. 2) Never steals focus (non-activating NSPanel, floating level, all Spaces). 3) Click-through ignores the mouse; a dashed outline and hotkey hint show it is on. 4) Resizable, remembers frame per display. 5) Opacity slider.

Trust & visibility

Default is visible mode: menu-bar recording indicator, pre-session reminder, consent note in onboarding and Settings. A cloud badge shows whenever a non-local provider is active. Shadow never offers undetectable features.

Native mapping

Overlay → nonactivating NSPanel + SwiftUI. Popover → NSPopover. Windows → AppKit hosting SwiftUI, destroyed on close. Settings → custom sidebar pane. Keys → Keychain. Audio → ScreenCaptureKit + AVAudioEngine. History → SwiftData.

Name: Shadow

Decided. A quiet presence beside you in the call — fits the overlay-at-your-shoulder idea. Alternatives considered: Cue, Murmur, Wingmate. Repo and Homebrew cask: shadow; if the cask name is taken, shadow-app. The bundle name and menu-bar tooltip are “Shadow”.

App icon

Speech bubble (conversation) holding four voice-level bars (live audio), on a violet→blue squircle. Drawn in code per the repo convention; the menu bar glyph is the same bubble+bars as a monochrome template image.
